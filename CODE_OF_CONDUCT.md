# Código de conduta

Este é um espaço pra aprender e criar junto. Valem três regras:

1. **Respeito sempre.** Nada de ofensa, preconceito, assédio ou ataque pessoal.
2. **Ajude quem está começando.** Toda pergunta é bem-vinda.
3. **Crie o que é seu.** Não envie marca, conteúdo ou material de outras pessoas sem permissão.

Quem não seguir pode ter comentários removidos ou ser bloqueado do projeto. Pra relatar um problema, abra uma issue ou fale com os mantenedores.
